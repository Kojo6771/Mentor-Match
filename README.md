# Mentor-Match
Mentor Match is a web-based tutoring and mentorship platform designed to connect university students with experienced peer mentors. The system allows students to discover, request, and communicate with mentors based on shared interests, academic background, and learning preferences.

The platform features user authentication, mentor profile creation, a mentor–mentee matching system, real-time chat functionality, and session booking capabilities. It also integrates an AI-powered chatbot to provide 24/7 academic support and guidance.

Built using HTML, CSS, JavaScript, and PHP with a MySQL database, Mentor Match focuses on delivering an intuitive and accessible user experience while supporting scalable and efficient backend operations.

This project was developed as part of a final-year Computer Science project, with an emphasis on usability, system design, and real-world applicability in supporting student success.
